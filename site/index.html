        Format reference
        
    
        
      
          
    • format — always 1. name — required. author, source — optional.
      • 
          
    • for — "main", "any" or a companion's name; a hint only.
      • 
          
    • start — character creation: race, raceBonus, abilityScores (point-buy values before the racial bonus, 7–18), alignment.
      • 
          
    • skills — the order skill points are spent in; a level may carry its own list.
      • 
          
    • levels — character levels 1–20 ascending: class, archetype (first level of that class), abilityPoint (levels 4, 8, …), picks, spells.
      • 
          
    • picks — { "in": page title, "pick": name }; nested choices as a list, parent first. A bare name works when it fits exactly one open page.
      • 
          
    • mythic — ranks 1–10: path where the game asks for it, picks.
      • 
        
    
        
    Not part of a build: portrait, appearance, voice, name, equipment.
